# cleat-fgo-build

自动构建并发布 FGO 日服汉化 APK。

[下载 APK](https://github.com/jhq223/cleat-fgo-build/releases/latest) · [手动构建](https://github.com/jhq223/cleat-fgo-build/actions/workflows/build.yml) · [汉化模块](https://github.com/jhq223/cleat-fgo) · [修改历史](CHANGELOG.md) · [构建文档](BUILD.md)

## 使用

从 Releases 下载 `fgo-mod.apk` 并安装。模块会检查后续更新，下载完成后通过 Android 下载通知打开安装包。
